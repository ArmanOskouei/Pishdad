# 📄 خلاصه تصمیمات پروژه (برای شروع سریع سشن)

> این فایل برای **کاهش خواندن فایل‌های بزرگ** است. سشن جدید اول این را بخواند؛ جزئیات را در صورت نیاز از فایل‌های مرجع کامل بگیرد.

## 🏗️ استک
- **Backend:** Laravel 11 (API-only) — همه دیتا و منطق
- **Frontend:** Next.js 15 (سایت عمومی + پنل /admin) — RTL فارسی + Vazirmatn
- **DB:** PostgreSQL (ICU fa-IR) + Redis + MinIO
- **میزبانی:** سرور اختصاصی (VPS/Dedicated) — تصمیم ۲۰۲۶/۰۹؛ طرح اولیه چابکان (PaaS) بود و کنار گذاشته شد
- **مدل:** اشتراکی (درآمد MRR) + تیربندی Budget/Standard/Enterprise

## 🧩 معماری کلیدی
- **هسته خام + پلاگین اعلانی:** پلاگین = manifest + کد لاراولی + schema بلوک، امضای Ed25519، چرخه حیات کامل
- **سوپرادمین:** توکن یکبارمصرف per-install (می‌سوزد)، فقط در پنل مرکزی
- **مدل انتشار محتوا:** تک‌منبع (page_blocks = پیش‌نویس، page_revisions = snapshot، published_revision_id تنها اشاره‌گر)
- **کش ISR چابکان اِفمِرال → cacheHandler روی Redis**
- **تعامل Laravel↔Next:** revalidate با HMAC + nonce + tag-based + purge آروان

## 💰 مدل کسب‌وکار
- **پرداخت مشتری:** از پنل خودش (بخش اشتراک) → درگاه فقط در پنل مرکزی (زرین‌پال/آیدی‌پی)
- **طیف زمانی:** D-7..D-0 یادآوری → D-0 تعلیق (سایت مسدود + پنل فقط-پرداخت) → D+5/D+6 هشدار → D+7 حذف
- **Provisioning:** تو تأمین می‌کنی (Laravel/Next اختصاصی، PG/MinIO/Redis اشتراکی)

## 🖥️ صفحات پنل (خلاصه)
- **پنل مشتری (۱۵ صفحه):** ورود+2FA، داشبورد، مدیران، پروفایل، **صفحات⭐**، فایل، تیکت، تنظیمات سایت، شبکه‌ها، پلاگین‌ها، هدر/فوتر⭐، بلوک‌ها⭐، قالب‌ها، **اشتراک⭐**، تعلیق(سایت)
- **پنل مرکزی (۷ صفحه):** داشبورد، **مشتریان⭐**، **چابکان⭐**، **Billing⭐**، مانیتورینگ، آپدیت‌ها، اپراتور
- نوار پایین موبایل: پیش‌فرض صفحات روزانه + انتخاب و ترتیب سراسری از «قالب پنل»

## 🎨 ۵ جهت بصری (برای پنل — همه قابل شخصی‌سازی)
سپیده (مینیمال) / عملیات (دارک کنسول) / آریا (رنگارنگ) / نرم (سافت) / دیوان (کلاسیک)
→ پیشنهاد: سپیده = مشتری، عملیات = مرکزی. صفحه ۱.۱۴ قالب پنل = انتخاب + پیش‌نمایش زنده + تأیید.
