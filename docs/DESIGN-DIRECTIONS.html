⭐ معماری سفارشی‌سازی ظاهر (الزام جدید)

پنل ادمین خودش قابل شخصی‌سازی توسط هر کاربر است:

  • تنظیم رنگ پس‌زمینه، فونت، شعاع گوشه‌ها، تراکم چیدمان
  • چند رنگ‌بندی پیشنهادی (Preset Themes) — ۵ جهت × ۳ پریست = ۱۵ ترکیب
  • دارک/لایت + ذخیره per-user
  • پیاده‌سازی با CSS Variables (تغییر پویا بدون رندر مجدد)
:root {
  --primary:#0D9488; --accent:#F59E0B;
  --bg:#F7F7F8; --surface:#FFFFFF; --text:#1A1A1E;
  --radius-sm:6px; --radius-md:10px; --radius-lg:14px;
  --font:"Vazirmatn", system-ui, sans-serif;
  --sidebar-w:260px; --topbar-h:64px; --density:1;
}
[data-theme="dark"] { /* بازتعریف */ }
[data-radius="sharp"] { --radius-sm:2px; --radius-md:4px; }
[data-radius="rounded"] { --radius-sm:8px; --radius-md:14px; }

جهت ۱ — «سپیده» (Sahar): مینیمال روشن

شخصیت: روشن، خنثی، White Space زیاد. حس سایت‌های مدرن فارسی. پیش‌فرض پنل مشتری.

توکنلایتدارک
--bg#F7F7F8#0E1114
--surface#FFFFFF#161A1F
--primary#0D9488 فیروزه‌ای#2DD4BF
--accent#F59E0B کهربایی#FBBF24
  • تایپو: وزن ۳۰۰-۷۰۰، ارتفاع خط 1.8، اعداد tabular
  • شعاع: کارت 12px، دکمه 8px — تراکم loose
  • سبک: دکمه تخت، کارت سفید + بوردر، سایدبار سفید با نوار 3px

Presets: فیروزه‌ای (پیش‌فرض) / نیلی #4F46E5 / یاقوتی #E11D48

جهت ۲ — «عملیات» (Amaliyat): دارک حرفه‌ای — کنسول اپراتور

شخصیت: حس DevOps. تیره، متراکم، StatusBadge نئونی. پیش‌فرض پنل مرکزی.

توکنلایت (فرعی)دارک (پایه)
--bg#F4F5F7#0A0B0F
--surface#FFFFFF#12141A
--primary#4F46E5 ایندیگو#6366F1
--accent#0891B2#22D3EE سایان
  • تایپو: وزن تا 900، ارتفاع 1.5، اعداد لاگ monospace
  • شعاع: کارت 8px، دکمه 6px — تراکم compact
  • سبک: کارت تیره + بوردر، جدول متراکم + StatusBadge، سایدبار مشکی‌تر

Presets: ایندیگو (پیش‌فرض) / ماتریس #10B981 / امنیت #F97316

جهت ۳ — «آریا» (Arya): مدرن رنگارنگ

شخصیت: جسور، جوان، گرادیانی. حس آژانس دیجیتال / SaaS. برای آژانس‌های برندمحور.

توکنلایتدارک
--bg#F5F6FB#0F0B1E
--surface#FFFFFF#171229
--primary#7C3AED بنفش#8B5CF6
--accent#EC4899 صورتی#F472B6
  • تایپو: وزن تا 900، اعداد آمار وزن 900
  • شعاع: کارت 16px، دکمه 12px — سایه رنگی
  • سبک: دکمه گرادیان بنفش→صورتی، آیکون در مربع رنگی، کارت ویژه با گرادیان

Presets: بنفش-صورتی (پیش‌فرض) / اقیانوس #0EA5E9 / غروب #F97316

جهت ۴ — «نرم» (Narm): سافت و دوستانه

شخصیت: گرم، گرد، ملایم. کاهش اضطراب مشتری غیرفنی. عالی برای حالت تعلیق/هشدار.

توکنلایتدارک
--bg#FAF7F2 کرم#1B1715
--surface#FFFFFF#251F1C
--primary#E07A5F سفالی#E8916F
--accent#81B29A سبز مریم‌گلی#9CC5AC
  • تایپو: وزن 300-700، ارتفاع خط 1.9 — خوانایی ماکسیمم
  • شعاع: کارت 20px، دکمه pill، فیلد 14px — تراکم loose
  • سبک: متن‌های دوستانه («چند روز تا سررسید مونده»)، خطرناک = قرمز گرم

Presets: سفالی (پیش‌فرض) / آسمانی #88A0B8 / لیمویی #A8C686

جهت ۵ — «دیوان» (Divan): کلاسیک مدیریتی

شخصیت: سنتی، اداری. حس وردپرس و cPanel — آشنا برای ایرانی‌ها. برای مهاجران وردپرس + برندهای رسمی.

توکنلایتدارک
--bg#EEF1F5#101418
--surface#FFFFFF#151A20
--primary#1D4ED8 آبی کبالت#3B82F6
--accent#0E7490#22D3EE
  • تایپو: بدنه 13.5px فشرده، ارتفاع 1.6
  • شعاع: کارت 6px، دکمه 4px — تراکم compact
  • سبک: سایدبار آبی تیره #1E293B، جدول zebra (الگوی wp-admin)، دکمه انتشار سبز

Presets: آبی کلاسیک (پیش‌فرض) / سبز دولتی #047857 / سرمه‌ای #1E3A8A
