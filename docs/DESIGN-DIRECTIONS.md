# 🎨 ۵ جهت بصری (Design Direction) — پنل مدیریت CMS

> **منبع:** بازخورد متخصص UI/UX (مدل DeepSeek V4 Flash از طریق OpenCode Go)
> **هدف:** انتخاب یک جهت بصری برای پنل ادمین — سپس اعمال آن در کل ۲۱ صفحه
> **الزام جدید:** پنل ادمین **خودش قابل شخصی‌سازی توسط هر کاربر** است (رنگ پس‌زمینه، فونت، شعاع، تراکم) + چند رنگ‌بندی پیشنهادی + دارک/لایت + پیاده‌سازی با CSS Variables (تغییر پویا بدون رندر مجدد) + ذخیره سراسری نصب
> تاریخ: شهریور ۱۴۰۵

## ⭐ معماری سفارشی‌سازی ظاهر (پیش‌نیاز همه ۵ جهت)

### توکن‌های CSS (همه تغییرات بدون رندر مجدد)
```css
:root {
  --primary: #0D9488;  --primary-hover: #0B7A70;
  --primary-soft: color-mix(in srgb, var(--primary) 10%, transparent);
  --accent: #F59E0B;   --accent-soft: color-mix(in srgb, var(--accent) 12%, transparent);
  --bg: #F7F7F8;       --surface: #FFFFFF;  --surface-2: #F0F1F3;
  --text: #1A1A1E;     --text-muted: #6B7280;
  --border: #E5E7EB;
  --success: #16A34A;  --warning: #D97706;  --danger: #DC2626;  --info: #2563EB;
  --radius-sm: 6px; --radius-md: 10px; --radius-lg: 14px; --radius-xl: 18px;
  --font: "Vazirmatn", system-ui, sans-serif;
  --shadow-sm: 0 1px 2px rgba(16,24,40,.06);
  --sidebar-w: 260px; --sidebar-w-collapsed: 64px; --topbar-h: 64px;
  --density: 1;
}
[data-theme="dark"] { /* بازتعریف برای تیره */ }
[data-radius="sharp"] { --radius-sm:2px; --radius-md:4px; --radius-lg:6px; }
[data-radius="rounded"] { --radius-sm:8px; --radius-md:14px; --radius-lg:20px; }
[data-density="compact"] { --space-4:10px; --fs-body:13px; }
```

### دامنه اتریبیوت‌های سفارشی‌سازی (روی `<html>`)
| اتریبیوت | مقادیر | کنترل |
|---|---|---|
| `data-theme` | `light` / `dark` / `system` | پالت پایه |
| `data-accent` | `teal` / `indigo` / ... | Preset رنگ اصلی |
| `data-radius` | `sharp` / `default` / `rounded` | شعاع گوشه‌ها |
| `data-density` | `compact` / `comfortable` / `loose` | تراکم |
| `data-font-size` | `sm` / `md` / `lg` | مقیاس فونت |

### ذخیره سراسری نصب
- جدول `settings` با کلید `group='ui'`، `key='global'` به‌صورت JSONB
- اعمال یک‌بار در ریشه ادمین Next.js → اتریبیوت روی `<html>` + `<style>` کوتاه
- تغییرات بعدی فقط JS خالص (بدون fetch/re-render)
- API: `GET/PUT /api/ui-settings` + هاک `UiSettingsTab` برای پلاگین‌ها
- **قانون:** هیچ رنگ هاردکدی در کامپوننت‌ها مجاز نیست — همه از متغیرها

# جهت ۱ — «سپیده» (Sahar): مینیمال روشن

### شخصیت
روشن، خنثی، با White Space زیاد. حس سایت‌های مدرن فارسی. برای **پیش‌فرض پنل مشتری**. کلمه کلیدی: آرام، صریح، قابل اعتماد.

### پالت
| توکن | لایت | دارک |
|---|---|---|
| `--bg` | `#F7F7F8` | `#0E1114` |
| `--surface` | `#FFFFFF` | `#161A1F` |
| `--text` | `#1A1A1E` | `#E7E9EC` |
| `--primary` | `#0D9488` (فیروزه‌ای) | `#2DD4BF` |
| `--accent` | `#F59E0B` (کهربایی) | `#FBBF24` |
| `--border` | `#E5E7EB` | `#262B31` |

### تایپوگرافی
Vazirmatn وزن ۳۰۰/۴۰۰/۵۰۰/۷۰۰ (بدون ۹۰۰). ارتفاع خط `1.8`. اعداد فارسی tabular.

### شعاع/سایه/تراکم
شعاع: کارت `12px`، دکمه `8px`. سایه: فقط `shadow-sm/md` — کارت‌ها عمدتاً با بوردر جدا می‌شن. تراکم: **loose** (پدینگ ۲۴px).

### سبک
- دکمه تخت، بدون گرادیان
- کارت سفید + بوردر ظریف، بدون سایه سنگین
- سایدبار سفید، آیتم فعال با `--primary-soft` + نوار ۳px
- هشدار با پس‌زمینه soft + آیکون، بدون بوردر

### Presets
1. **سپیده فیروزه‌ای** — `#0D9488` + `#F59E0B` (پیش‌فرض)
2. **سپیده نیلی** — `#4F46E5` + `#06B6D4`
3. **سپیده یاقوتی** — `#E11D48` + `#F59E0B`

### دارک/لایت
لایت = شخصیت اصلی. دارک = شب ملایم (کاهش کنتراست، نه مشکی خالص). سایه در دارک → بوردر.

### پالت

| `--bg` | `#F4F5F7` | `#0A0B0F` |

| `--text` | `#1F2430` | `#E6E9F0` |
| `--primary` | `#4F46E5` (ایندیگو) | `#6366F1` |
| `--accent` | `#0891B2` | `#22D3EE` (سایان) |
| `--success` | `#059669` | `#34D399` (نئون) |
| `--danger` | `#DC2626` | `#F87171` |

### تایپوگرافی
وزن ۴۰۰/۵۰۰/۷۰۰/۹۰۰. ارتفاع خط `1.5`. در لاگ/دیپلوی: اعداد monospace (فارسی فقط ستون متنی).

### شعاع/سایه/تراکم
شعاع **کوچک**: کارت `8px`، دکمه `6px`. سایه فقط مودال‌ها؛ کارت با بوردر `#23262F`. تراکم: **compact** (پدینگ ۱۶px).

### سبک
- دکمه لبه تیز، دکمه خطرناک با بوردر قرمز روشن
- کارت تیره + بوردر نازک + آیکون status
- جدول متراکم (ردیف ۱۴px) + StatusBadge رنگی
- سایدبار مشکی‌تر (`#0E1016`)، آیتم فعال با بوردر ایندیگو
- هشدار با آیکون solid + عنوان پررنگ

### Presets
1. **عملیات ایندیگو** — `#6366F1` + `#22D3EE` (پیش‌فرض مرکزی)
2. **عملیات ماتریس** — `#10B981` + `#A3E635`
3. **عملیات امنیت** — `#F97316` + `#F43F5E`

### دارک/لایت
**دارک = شخصیت اصلی.** لایت نسخه «دفتر روشن». پنل مرکزی پیش‌فرض دارک.

### تایپوگرافی

3. **آریا غروب** — `#F97316` + `#F43F5E`

### دارک/لایت

# جهت ۴ — «نرم» (Narm): سافت و دوستانه

گرم، گرد، ملایم. حس اپ‌های سلامت/بانکداری دوستانه. هدف: **کاهش اضطراب** مشتری غیرفنی. عالی برای حالت تعلیق/هشدار (تهدید به نظر نرسد). کلمه کلیدی: آرامش، اعتماد، گرمی.

### پالت
| توکن | لایت | دارک |
|---|---|---|
| `--bg` | `#FAF7F2` (کرم) | `#1B1715` |
| `--surface` | `#FFFFFF` | `#251F1C` |
| `--text` | `#33302E` | `#F0EAE6` |
| `--primary` | `#E07A5F` (سفالی) | `#E8916F` |
| `--accent` | `#81B29A` (سبز مریم‌گلی) | `#9CC5AC` |
| `--border` | `#EFE6DF` | `#3A322C` |

### تایپوگرافی
وزن ۳۰۰/۴۰۰/۵۰۰/۷۰۰ (پرهیز از ۹۰۰). ارتفاع خط `1.9` — خوانایی ماکسیمم.

### شعاع/سایه/تراکم
شعاع **خیلی گرد**: کارت `20px`، دکمه `pill`، فیلد `14px`. سایه نرم پخش‌شده. تراکم: **loose** (بزرگ‌ترین فاصله‌ها).

### سبک
- دکمه بزرگ گرد (pill) + سایه ملایم
- کارت گوشه ۲۰px بدون بوردر تیز
- متن‌های دوستانه: «چند روز تا سررسید مونده»، «عالیه، صفحه منتشر شد!»
- خطرناک = قرمز گرم `#D9796B` (نه قرمز خونی)

### Presets
1. **نرم سفالی** — `#E07A5F` + `#81B29A` (پیش‌فرض)
2. **نرم آسمانی** — `#88A0B8` + `#F2CC8F`
3. **نرم لیمویی** — `#A8C686` + `#F4A261`

### دارک/لایت
لایت: کرم گرم (نه سفید خالص). دارک: قهوه‌ای گرم `#1B1715` — حس «چای دور هم» نه «دفتر فنی».

### تایپوگرافی
وزن ۴۰۰/۶۰۰/۷۰۰/۸۰۰. بدنه `13.5px` (فشرده). ارتفاع خط `1.6`. بدون تیترهای بزرگ.

## ✅ توصیه استراتژیک

1. **دو جهت پیش‌فرض سیستم:** «سپیده» برای پنل مشتری + «عملیات» برای پنل مرکزی (کمترین ریسک، دقیقاً مطابق مخاطب هر پنل)
2. **بقیه جهت‌ها = Preset Theme کامل** در تنظیمات ظاهر: هر کاربر می‌تواند از هر ۵ جهت + ۳ رنگ‌بندی هر جهت استفاده کند → **۱۵ ترکیب اولیه**
3. **ساختار پیاده‌سازی:** `tokens/base.css` (مشترک) + ۵ فایل `tokens/direction-*.css` (هر جهت فقط متغیرها را بازتعریف می‌کند) + `presets.css` (رنگ‌بندی‌ها). هیچ کامپوننتی به جهت خاصی وابسته نیست — تعویض جهت = تعویض لایه توکن.
