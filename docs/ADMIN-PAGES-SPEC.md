# بخش ۱ — پنل مشتری (۱۵ صفحه + ۱ عمومی)

## ۱.۱ — ورود + 2FA (کم)

**مشخصات:** فرم ایمیل/نام کاربری + رمز + گام دوم کد 2FA (پیامک/Authy) + لینک فراموشی رمز. اگر سایت معلق باشد → بعد از لاگین مستقیم به «اشتراک من». پیام خطای یکسان برای «کاربری/رمز غلط».

**وایرفریم:** چیدمان تمام‌صفحه (خارج از Shell). کارت وسط (~۴۰۰px) + لوگو. **دو گام در یک کارت** (انیمیشن تعویض):
- گام ۱: فیلد + رمز + ورود + «فراموشی رمز»
- گام ۲ (شرطی): کد 2FA (۶ رقم، خودکار-انتقال) + تأیید + «کد بازیابی» + ارسال مجدد (شمارش معکوس)
- ⭐ حالت معلق: بعد از گام ۱ → مستقیم به «اشتراک من» + بنر زرد (دو واریانت رسم شود)

## ۱.۲ — داشبورد (متوسط)

**مشخصات:** کارت‌های آمار (صفحات/فایل/تیکت/وضعیت اشتراک) + اسلات ویجت پلاگین (با حالت خالی) + هشدارها + میانبرها.

**وایرفریم:** ردیف ۱: خوش‌آمد + ۳ میانبر (صفحه جدید/آپلود فایل/پاسخ تیکت). ردیف ۲: ۴ کارت آمار (کارت اشتراک معلق → قرمز). ردیف ۳: بنرهای هشدار (فقط فعال + حالت خالی). ردیف ۴: گرید ویجت پلاگین ۲×۲ با **حالت خالی قابل طراحی**. ویجت‌ها از رجیستری `DashboardWidget` تغذیه می‌شوند.

## ۱.۳ — مدیران + نقش‌ها (متوسط)

**مشخصات:** لیست مدیران + ایجاد/ویرایش + نقش‌ها و دسترسی‌ها (چک‌باکس ماژول‌ها). ⚠️ سوپرادمین **در هیچ‌جا لیست نمی‌شود** (صرفاً غایب، حتی با قفل).

**وایرفریم:** الگوی **Tab دوگانه**: `مدیران | نقش‌ها و دسترسی‌ها`. مدیران: نوار ابزار (جستجو + فیلتر نقش + «مدیر جدید») + جدول + مودال. نقش‌ها: لیست نقش (ستون راست) + پنل چک‌باکس (ستون چپ، گروه‌بندی ماژول).

## ۱.۴ — پروفایل مدیر (متوسط) ⭐ الگوی «Section Slot»

**مشخصات:** اطلاعات پایه (نام/ایمیل/تلفن) + رمز + بخش‌های 2FA داینامیک (پلاگینی: پیامک/Authy/QR/کد بازیابی).

**وایرفریم:** دو ستونه (راست محتوا، چپ امنیت). چپ = Container با **اسلات رندر** — هر پلاگین بخش اضافه می‌کند. ⚠️ **این الگو کلید سیستم است:** «اسلات داینامیک پلاگینی» در داشبورد/تنظیمات/سایدبار هم لازم است → یک الگوی «Section Slot» طراحی شود (وگرنه هر پلاگین = بازطراحی).

## ۱.۵ — مدیریت صفحات ⭐⭐ (زیاد — مهم‌ترین صفحه)

**مشخصات:** لیست صفحات + ویرایشگر بلوکی (Jodit + بلوک‌ها با درگ‌اندروپ) + تاریخچه نسخه + سئو + پیش‌نمایش + انتشار.

**وایرفریم — دو حالت:**
**حالت A) لیست:** نوار ابزار (جستجو + فیلتر وضعیت/دسته + «صفحه جدید») + جدول (عنوان/اسلاگ/وضعیت Badge/آخرین ویرایش/اکشن) + صفحه‌بندی.

**حالت B) ویرایشگر — تمام‌صفحه Immersive (بدون سایدبار):**
- تاپ‌بار: بازگشت + عنوان/اسلاگ + وضعیت (Dropdown) + دکمه‌ها: `ذخیره پیش‌نویس`(خاکستری) `پیش‌نمایش`(تب جدید با توکن HMAC) `انتشار`(سبز)
- ستون وسط — بوم بلوک‌ها: لیست عمودی، هر بلوک = کارت (هندل درگ + آیکون + تنظیمات) + drop zone بین بلوک‌ها + «افزودن بلوک» → Drawer کتابخانه بلوک (متن/تصویر/گالری/ویدئو/CTA/آکاردئون/نقشه). بلوک متن → Jodit داخل خود بلوک
- سایدبار راست — Inspector: ① عمومی (قالب/لایه‌اوت/زمان انتشار) ② سئو (عنوان/توضیحات/og-image/canonical) ③ نسخه‌ها (لیست + «بازگشت به این نسخه»)
- «انتخاب تصویر» همه‌جا → مودال مشترک **MediaPicker**
- ⭐ الگو: **«Canvas + Inspector»** (مثل Webflow/Elementor) — انتخاب بلوک → Inspector آن بلوک (Two-way binding)
- بنر «ادمین دیگری در حال ویرایش است» (قفل advisory)

## ۱.۶ — مدیریت فایل (متوسط)

**مشخصات:** گالری/لیست + آپلود + سطل زباله + alt/URL + جستجو.

**وایرفریم:** نوار ابزار (آپلود + سوییچ گرید/لیست + فیلتر نوع + جستجو + سطل زباله). گرید: آیکون‌های بزرگ + تیک هاور + کلیک → **Drawer راست** (پیش‌نمایش + نام/alt/URL + کپی + ویرایش + حذف). آپلود: مودال DropZone + پیشرفت چندفایله. ⚠️ **MediaPicker = اولین کامپوننت طراحی شود** (۵ صفحه وابسته). ⚠️ نشانگر مصرف/سقف تیر.

## ۱.۷ — تیکت‌ها (متوسط)

**مشخصات:** لیست تیکت‌ها + گفتگو + پاسخ + وضعیت + اعلان.

**وایرفریم:** الگوی **Master-Detail اسپلیت** (RTL: لیست راست، گفتگو چپ). لیست: جدول فشرده (موضوع/فرستنده/وضعیت Badge/زمان) + فیلتر. گفتگو: حباب چت + نوار پاسخ (Textarea + چک‌باکس «اطلاع‌رسانی به فرستنده» + ارسال + بستن). موبایل: لیست → گفتگو با دکمه بازگشت.

## ۱.۸ — تنظیمات سایت (کم)

**مشخصات:** عنوان/توضیحات/لوگو/فاوآیکون/تلفن/ایمیل.

**وایرفریم:** فرم کارتی (هویت/لوگو+فاوآیکون با MediaPicker/تماس) + **Sticky SaveBar** (الگوی همه فرم‌ها).

## ۱.۹ — شبکه‌های اجتماعی (کم)

**مشخصات:** لینک + آیکون هر شبکه.

**وایرفریم:** لیست ردیفی: آیکون پیش‌فرض + نام + لینک + آیکون سفارشی + حذف + سوییچ نمایش. «افزودن شبکه» + Empty state. از کتابخانه آیکون برند استفاده شود (آپلود اختیاری).

## ۱.۱۰ — پلاگین‌ها (متوسط)

**مشخصات:** لیست + آپلود + فعال/غیرفعال + هشدار آپدیت. ⚠️ نصب/حذف فقط سوپرادمین؛ مشتری فقط فعال/غیرفعال.

**وایرفریم:** نوار ابزار (جستجو + آپلود) + جدول/کارت (نام/نسخه/سوییچ وضعیت/توضیح/اکشن + Badge آپدیت). ⚠️ **رندر شرطی نقش:** `can(action)` — حذف/آپلود فقط سوپرادمین. پیام «برای نصب/حذف به پشتیبانی مراجعه کنید» برای مشتری عادی.

## ۱.۱۱ — هدر/فوتر ⭐ (زیاد) — الگوی «Widget Area»

**مشخصات:** درگ‌اندروپ ویجت‌ها (لینک صفحات/فرم لاگین/منو/لوگو/متن/شبکه‌ها) در هدر و فوتر.

**وایرفریم:** ستون راست = پالت ویجت‌های قابل کشیدن. ستون چپ = بوم با دو ناحیه هدر/فوتر (drop zone افقی) + درگ/جابجایی + کلیک → Drawer تنظیمات ویجت (SchemaForm). سوییچ پیش‌نمایش زنده (دسکتاپ/موبایل). ⚠️ **با ۱.۱۲ یک طراحی مشترک** — یک `DragDropList` + یک `WidgetSettingsForm`.

## ۱.۱۲ — بلوک‌های سایت ⭐ (زیاد)

**مشخصات:** درگ‌اندروپ بلوک‌های هر نوع صفحه (فیلتر محصولات و...).

**وایرفریم:** مشابه ۱.۱۱ با **Tab به‌ازای نوع صفحه** (محصولات/بلاگ/...). هر Tab: بوم بلوک‌های پیش‌فرض + درگ‌اندروپ + سوییچ فعال + Drawer تنظیمات. ⚠️ فهرست «انواع صفحه» و بلوک‌های پیش‌فرض تعریف نشده — قبل از وایرفریم لازم است.

## ۱.۱۳ — قالب‌ها (متوسط)

**مشخصات:** گالری کارت + فعال‌سازی + پیش‌نمایش + آپلود + حذف.

**وایرفریم:** الگوی **Theme Gallery** (وردپرس): گرید کارت بزرگ (اسکرین‌شات + نام + نسخه + فعال‌سازی/پیش‌نمایش/حذف) + قالب فعال قاب سبز + «آپلود قالب». ⚠️ تصمیم: پیش‌نمایش = iframe واقعی یا تصویر؟ (MVP: تصویر). حذف قالب فعال ممنوع.

## ۱.۱۴ — قالب پنل مدیریت ⭐ (ظاهر پنل ادمین)

**مشخصات:** این صفحه برای **شخصی‌سازی ظاهر مشترک پنل مدیریت** است — مدیران نصب می‌توانند قالب پنل را از بین قالب‌های از پیش طراحی‌شده انتخاب کنند. این جدا از صفحه «۱.۱۳ قالب‌ها» است (که قالب **سایت** را مدیریت می‌کند). قالب پنل با **CSS Variables** پیاده‌سازی می‌شود (تغییر پویا بدون رندر مجدد) و به‌صورت **سراسری برای نصب** ذخیره می‌شود.

### امکانات صفحه
- **گرید کارت قالب‌ها:** ۵ قالب پیش‌فرض پنل (سپیده/عملیات/آریا/نرم/دیوان) به‌صورت کارت با **پیش‌نمایش مینیاتوری** هر قالب
- **پیش‌نمایش زنده (Live Preview):** با کلیک روی هر کارت، قالب **فوراً روی همان پنل** اعمال می‌شود (بدون ذخیره) تا کاربر تغییرات را ببیند
- **نشان قالب فعال:** قالب فعال فعلی با نشان «✔ فعال» + قاب سبز
- **نشان پیش‌نمایش:** وقتی کاربر روی قالب دیگری کلیک می‌کند، نشان «پیش‌نمایش» نمایش داده می‌شود
- **نوار ذخیره (SaveBar):** پایین صفحه چسبان — با دکمه‌های «انصراف از پیش‌نمایش» و «تأیید و ذخیره قالب»
- **انتخاب روشن/تیره:** سوییچ لایت/دارک برای دیدن قالب در هر دو حالت قبل از تأیید
- **رنگ‌بندی‌های پیشنهادی (Presets):** هر قالب ۲-۳ رنگ‌بندی دارد که کاربر می‌تواند انتخاب کند (۱۵ ترکیب کل)
- **تنظیمات پیشرفته (اختیاری):** شعاع گوشه‌ها، تراکم چیدمان، اندازه فونت

**وایرفریم:**
```
[ هدر صفحه: عنوان + توضیح + نشان «قالب فعال: X» ]
┌─────────────┬─────────────┬─────────────┐
│ کارت قالب ۱ │ کارت قالب ۲ │ کارت قالب ۳ │
│ [پیش‌نمایش] │ [پیش‌نمایش] │ [پیش‌نمایش] │
│ سپیده       │ عملیات      │ آریا        │
│ ✔ فعال      │ ◉ پیش‌نمایش │             │
│ [۳ پریست رنگی]│ [۳ پریست]  │ [۳ پریست]  │
├─────────────┼─────────────┼─────────────┤
│ کارت قالب ۴ │ کارت قالب ۵ │             │
│ نرم         │ دیوان       │             │
└─────────────┴─────────────┴─────────────┘
[ نوار ذخیره چسبان: (پیش‌نمایش) قالب «X» انتخاب شد
  [انصراف از پیش‌نمایش]  [تأیید و ذخیره قالب] ]
```

**نکته UI/UX:** کارت‌ها باید **پیش‌نمایش واقعی** (مینیاتور با رنگ‌های همان قالب) داشته باشند نه فقط نام. انتخاب = اعمال فوری، تأیید = ذخیره نهایی. ⚠️ این صفحه با «تنظیمات ظاهر» در پروفایل کاربر (بخش ۱.۴) هماهنگ است — تغییر از هر دو نقطه اعمال می‌شود.

### بازخورد وایرفریم (تکمیل — حاصل بررسی متخصص)

**۱. State Machine صریح (مهم‌ترین):** `saved → previewing(dirty) → confirmed | canceled`
- همه ورودی‌های صفحه (جهت + اکسنت + لایت/دارک + شعاع + تراکم + فونت) یک state واحد هستند
- با «تأیید» یکجا ذخیره می‌شوند، با «انصراف» یکجا به `saved` برمی‌گردند
- ⚠️ سوییچ لایت/دارک و پریست‌ها هم بخشی از state پیش‌نمایش هستند (نه ذخیره فوری)

**۲. مینیاتور Token-Driven (نه هاردکد):**
- مینیاتور هر کارت از همان CSS Variables جهت ساخته شود (`var(--bg)`, `var(--sidebar-bg)`, `var(--primary)`...) تا با تغییر پریست/شعاع زنده بماند
- شامل: مینی-سایدبار (راست، RTL) + مینی-تاپ‌بار + مینی-بادی (۲-۳ کارت آمار + ردیف جدول)
- امضای بصری هر جهت اغراق شود (دیوان = سایدبار آبی تیره، عملیات = مشکی + ایندیگو، آریا = گرادیان بنفش-صورتی)
- هاور کارت → مینیاتور کمی بزرگ‌تر (دومین سطح پیش‌نمایش)

**۳. حالت‌های مرزی (۱۱ مورد):**
| # | حالت مرزی | رفتار |
|---|---|---|
| ۱ | ترک صفحه با پیش‌نمایش فعال | مودال «تغییرات ذخیره نشده» (ادامه/انصراف) + beforeunload |
| ۲ | لایت/دارک در حین پیش‌نمایش | جزو state پیش‌نمایش — فقط با تأیید ذخیره |
| ۳ | تغییر پریست در حین پیش‌نمایش | انصراف، اکسنت را هم برمی‌گرداند |
| ۴ | کلیک روی قالب فعال | «پیش‌نمایش مجدد» برای دیدن با پریست/تنظیمات جدید |
| ۵ | تأیید بدون تغییر | دکمه disabled |
| ۶ | شکست شبکه هنگام ذخیره | خطا در SaveBar + حفظ پیش‌نمایش برای تلاش مجدد |
| ۷ | اولین ورود / بدون تنظیم | پیش‌فرض: «سپیده» (مشتری) / «عملیات» (مرکزی) + نشان «پیش‌فرض» |
| ۸ | ورود مجدد پس از پیش‌نمایش نیمه‌کاره | همگام با قالب ذخیره‌شده |
| ۹ | دو تب باز / تغییر از ۱.۴ | همگام سراسری نصب (اختیاری) |
| ۱۰ | قالب ذاتاً دارک (عملیات) در لایت | مجاز + توضیح «پیش‌فرض این قالب دارک است» |
| ۱۱ | ریلود در حین پیش‌نمایش | برگشت به ذخیره‌شده + توست |

**۴. جای پریست و لایت/دارک:**
- **پریست‌ها داخل هر کارت** (وابسته به جهت) — زیر پیش‌نمایش، با حلقه + تیک روی swatch
- **لایت/دارک در SaveBar** — قطاعی `لایت | دارک` کنار دکمه‌ها (نوار کنترل پیش‌نمایش واحد)

**۵. تنظیمات پیشرفته (اختیاری):**
- بخش آکاردئونی «تنظیمات پیشرفته» بالای SaveBar: شعاع (تیز/پیش‌فرض/گرد)، تراکم (فشرده/متوسط/باز)، فونت (کوچک/متوسط/بزرگ)
- پیش‌فرض بسته — تغییرات زنده، جزو state پیش‌نمایش

**۶. کامپوننت‌های مشترک:** `ThemeCard` (کارت قالب) + `AppearancePanel` (تنظیمات ظاهر) یک‌بار طراحی شوند و در ۱.۱۴ و پروفایل (۱.۴) استفاده شوند. دکمه «بازنشانی به پیش‌فرض» در SaveBar.

**۷. تمایز بصری:** نشان «پیش‌نمایش» (کهربایی) ≠ «فعال» (سبز). منوی «قالب پنل» (۱.۱۴) و «قالب‌های سایت» (۱.۱۳) صریحاً جدا شوند.

### طراحی نهایی UIUX (کاملاً قابل اجرا)

**State Machine:** یک شیء واحد `AppearanceState` = `{ dir, preset, mode, radius, density, fontSize }`. فازها: `saved → previewing(dirty) → confirmed | canceled`. هر ورودی (حتی لایت/دارک و پریست) → `mutate()` → پیش‌نمایش. `confirm()` فقط با `isDirty`، `cancel()` کل draft را دور می‌ریزد. `reset()` از مسیر mutate می‌رود (قابل انصراف).

**کامپوننت `ThemeCard`:**
- Props: `dir, name, tagline, presets[], defaultMode, presetIndex, mode, radius, density, fontSize, isActive, isPreviewing, isDefault, onSelect, onPresetSelect, disabled`
- کارت `role="radio"` + ناوبری کیبورد (Enter/Space/جهت‌ها)
- وضعیت‌ها: `is-active` (قاب سبز + ✔ فعال) / `is-previewing` (قاب کهربایی + ◉ پیش‌نمایش — غلبه بر سبز، تیک سبز می‌ماند) / `is-default` (چیپ «پیش‌فرض») / `is-disabled` (اسکلتون)
- **مینیاتور Token-Driven:** روی `.tc-preview` شش اتریبیوت (direction/mode/preset/radius/density/font) — بدون رنگ هاردکد، همه از `var(--bg)`, `var(--sidebar-bg)`, `var(--primary)`, `var(--grad)`... ساختار: مینی-سایدبار (راست RTL) + مینی-تاپ‌بار + مینی-بادی (کارت آمار + ردیف جدول). هاور → `scale(1.04)`. امضای بصری هر جهت از توکن‌ها می‌آید (دیوان = سایدبار سرمه‌ای، عملیات = مشکی+ایندیگو، آریا = گرادیان لوگو)
- پریست‌ها داخل کارت: `role="radiogroup"` + swatch با `--swatch` + تیک/حلقه انتخاب

**کامپوننت `AppearancePanel` (مشترک با پروفایل ۱.۴):**
- Props: `value, onChange, sections[], variant('page'|'profile'), collapsible, defaultOpen`
- کنترل‌ها: mode (لایت/دارک)، radius (تیز/پیش‌فرض/گرد)، density (فشرده/متوسط/باز)، font (کوچک/متوسط/بزرگ) — همه `SegmentedControl` با `role="radiogroup"`
- در ۱.۱۴ آکاردئونی بسته + مود داخل SaveBar؛ در ۱.۴ پنل باز

**چیدمان صفحه:**
```
[هدر: قالب پنل مدیریت | قالب فعال: سپیده ✔ | چیپ پیش‌فرض]
[گرید کارت‌ها: ۵ کارت با مینیاتور + نام + نشان + پریست‌ها]
▸ تنظیمات پیشرفته (اختیاری) [بسته] — شعاع/تراکم/فونت
[SaveBar چسبان: ◉ پیش‌نمایش: قالب X ... | لایت|دارک | بازنشانی | انصراف | تأیید و ذخیره]
```

**۱۱ حالت مرزی (پیاده‌سازی):** ترک صفحه → مودال «تغییرات ذخیره‌نشده» + beforeunload | لایت/دارک جزو draft | پریست جزو draft | کلیک روی قالب فعال → پیش‌نمایش مجدد | تأیید بدون تغییر → disabled | شکست شبکه → خطا در SaveBar + تلاش مجدد | اولین ورود → پیش‌فرض نقش (سپیده مشتری/عملیات مرکزی) | ریلود → برگشت به saved + توست | دو تب → فاز ۲ | قالب دارک در لایت → توضیح hint | همه → hydrated از saved

**توکن‌های پریست (۱۵ ترکیب):**
| جهت | پریست ۰ | پریست ۱ | پریست ۲ |
|---|---|---|---|
| سپیده | فیروزه‌ای #0D9488 | نیلی #4F46E5 | یاقوتی #E11D48 |
| عملیات | ایندیگو #6366F1 | ماتریس #10B981 | امنیت #F97316 |
| آریا | بنفش-صورتی (گرادیان) | اقیانوس (گرادیان) | غروب (گرادیان) |
| نرم | سفالی #E07A5F | آسمانی #88A0B8 | لیمویی #A8C686 |
| دیوان | آبی کلاسیک #1D4ED8 | سبز دولتی #047857 | سرمه‌ای #1E3A8A |

`--primary-soft` با `color-mix(in srgb, var(--primary) 10%, transparent)` مشتق شود. پالت‌های دارک پریست ۱/۲ با `lighten(12%)` در build-time.

**DoD پیاده‌سازی:** ماشین حالت کامل | مینیاتور بدون هاردکد | پریست در کارت + مود در SaveBar | آکاردئون تنظیمات | ۱۱ حالت مرزی تست‌شده | بازنشانی + تمایز کهربایی/سبز | ThemeCard/AppearancePanel مستقل | RTL logical + اسکلتون | ضد FOUC (اسکریپت قبل از paint)

## ۱.۱۵ — اشتراک من ⭐ (قلب «حلقه پول»)

**مشخصات:** وضعیت پلن + دوره (ماهانه/سالانه با ۲۰٪ تخفیف) + فاکتور + دکمه پرداخت (درگاه در مرکزی) + تاریخچه + حالت تعلیق (فقط این صفحه فعال).

**وایرفریم:** کارت وضعیت (پلن تگ رنگی + سوییچ دوره + سررسید + وضعیت) + فاکتورها (جدول + دکمه «پرداخت» سبز) + تاریخچه + حالت تعلیق (بنر قرمز + سایدبار قفل). ⭐ **جریان پرداخت = Stepper جدا:** فاکتور → درگاه (پیام «در حال انتقال...») → نتیجه → بازگشت. ⚠️ سیاست «ارتقا تیر توسط مشتری» و proration تعریف نشده.

## ۱.۱۶ — تعلیق عمومی (کم — سمت سایت)

**مشخصات:** پیام «اشتراک هاست شما تمام شده است...» بدون لینک پنل.

**وایرفریم:** صفحه تمام‌صفحه با برند سایت + آیکون + پیام + دکمه تماس پشتیبانی — **بدون لینک /admin**. حیاتی برای UX (مشتری باید بداند چه کند).

# بخش ۲ — پنل مرکزی (۷ صفحه — فقط کارفرما)

## ۲.۱ — داشبورد مرکزی (متوسط)

**مشخصات:** آمار (مشتریان فعال/درآمد/معلق/هشدار) + هشدارهای اکشن‌دار + نمودارها.

**وایرفریم:** ۴ کارت + هشدارهای قابل اکشن (کیف پول قرمز/استخر زرد/تعلیق زرد/دیپلوی قرمز → لینک به صفحه) + نمودارها (درآمد خطی/مشتری میله‌ای). این «نگاه اول صبح» کارفرماست — پرونده‌های باز را نشان دهد.

## ۲.۲ — مدیریت مشتریان ⭐ (زیاد) — Master-Detail با Drawer

**مشخصات:** لیست + جزئیات + ساخت مشتری + ارتقا تیر + تعلیق/بازگشایی + توکن پشتیبانی.

**وایرفریم:** لیست جدول غنی (نام/دامنه لینک/تیر Tag/اشتراک Badge/نسخه/سلامت دایره‌ای/اکشن) + «مشتری جدید». **Drawer عریض (~۶۴۰px) با تب‌ها:** ① اطلاعات ② سرویس‌ها ③ بکاپ‌ها ④ فاکتورها. اکشن: **«ارتقا تیر»** (ConfirmDialog دو مرحله‌ای + progress) + **«دسترسی پشتیبانی»** (توکن یکبارمصرف → کپی + TTL). مودال مشتری جدید: فرم + خلاصه هزینه.

## ۲.۳ — مدیریت چابکان ⭐ (زیاد) — Ops Console

**مشخصات:** موجودی کیف پول + استخر سرویس + سرویس‌های مشتریان (start/stop/restart/resize) + دیپلوی + reconciliation.

**وایرفریم:** ردیف ۱: موجودی کیف پول (هشدار زیر ۲ ماه) + استخر سرویس (تعداد Idle + هشدار خالی). ردیف ۲: سرویس‌های مشتریان (وضعیت Badge + اکشن‌ها — همه ConfirmDialog). ردیف ۳: دیپلوی‌ها (تاریخچه + «دیپلوی مجدد»). ردیف ۴: Reconciliation. ⭐ **StatusBadge + ActionMatrix** کامپوننت مشترک (وضعیت → اکشن‌های مجاز).

## ۲.۴ — صورتحساب/Billing ⭐ (زیاد) — Tab پنج‌گانه

**مشخصات:** پلن‌ها + فاکتورها + پرداخت‌ها + کنترل تعلیق + تنظیمات درگاه.

**وایرفریم — Tab پنج‌گانه:**
1. **پلن‌ها:** CRUD (نام/قیمت ماهانه/سالانه/تیر/منابع)
2. **فاکتورها:** جدول همه + فیلتر + «فاکتور دستی» + **قابل چاپ/PDF**
3. **پرداخت‌ها:** تراکنش‌ها (کد پیگیری/مشتری/مبلغ/وضعیت) + جستجوی درگاه
4. **کنترل تعلیق:** ⭐ مهم‌ترین — مشتریان معلق (مشتری/روز باقی‌مانده از ۷ روز/آخرین اقدام) + اکشن (اعلان/حذف قرمز/بازگشایی)
5. **تنظیمات درگاه:** انتخاب درگاه فعال + کلید (ماسک) + حالت تست

## ۲.۵ — مانیتورینگ (متوسط)

**مشخصات:** گرید سلامت + لاگ متمرکز + آپتایم.

**وایرفریم:** تب ۱: گرید سلامت (نام + دایره سبز/زرد/قرمز + آخرین check). تب ۲: لاگ متمرکز (فیلتر مشتری/سرویس/سطح + جدول + لود-بیشتر). تب ۳: آپتایم ۳۰ روز. ⚠️ منبع داده heartbeat تعریف نشده (فرض: هر ۱ دقیقه).

## ۲.۶ — آپدیت‌ها (متوسط)

**مشخصات:** نسخه نصب‌ها + آپدیت پلکانی.

**وایرفریم:** جدول نصب‌ها (نسخه نصب‌شده/آخرین نسخه) + Badge «آپدیت موجود» + دکمه آپدیت (ConfirmDialog). رول‌اوت پلکانی: پایلوت → بچّه → همه + نوار پیشرفت + **Rollback برجسته در شکست** (قرمز). ⚠️ UI نباید مفهوم canary داشته باشد.

## ۲.۷ — پروفایل اپراتور (کم)

**مشخصات:** 2FA سخت‌افزاری + مدیریت توکن راه‌اندازی + لاگ فعالیت.

**وایرفریم:** راست: 2FA (QR) + مدیریت توکن (بازتولید → **step-up auth**) + **Kill-Switch** (قرمز ترسناک + تأیید دومرحله‌ای). چپ: لاگ فعالیت (ورود/دیپلوی/تولید توکن/IP).
