🎯 جریان کار و قوانین کلی

هر تسک ۳ فاز دارد: UIUX (طراحی) → Backend (ساخت API مطابق طراحی) → Frontend (پیاده‌سازی نهایی).

[شروع] → [UIUX طراحی] → [Backend ساخت API] → [Frontend پیاده‌سازی] → [DoD تأیید] → [تمام/بازگشت]
  • کامپوننت‌های مشترک (DataTable, SchemaForm, MediaPicker, DragDropList, ThemeCard, AppearancePanel) در مرحله ۰ ساخته می‌شوند
  • هسته UI مشترک — دو پنل (مشتری + مرکزی) از یک هسته
  • Contract-first: OpenAPI واحد + تولید تایپ TypeScript برای Next.js
  • RTL + فونت Vazirmatn + دارک/لایت در همه صفحات

🟦 مرحله ۰ — زیرساخت مشترک (پیش‌نیاز همه)

تسک ۰.۱ — هسته UI

UIUX: ۴ کامپوننت قراردادی (DataTable/SchemaForm/MediaPicker/DragDropList) + ThemeCard/AppearancePanel + SaveBar/Modal/Drawer/ConfirmDialog/EmptyState/SegmentedControl.

Backend: OpenAPI هسته (auth, ui-settings). Frontend: پیاده‌سازی کامپوننت‌ها + RTL + فونت + توکن‌ها.

تسک ۰.۲ — انتخاب جهت بصری

UIUX: انتخاب از DESIGN-DIRECTIONS (سپیده مشتری + عملیات مرکزی). Backend: جدول settings گروه ui + GET/PUT /api/ui-settings. Frontend: سیستم تم (CSS Variables + ضد FOUC).

🟩 مرحله ۱ — هسته حلقه پول (اولین محصول قابل فروش)

تسک ۱.۱ — صفحه ۱.۵: مدیریت صفحات ⭐⭐

UIUX: لیست + ویرایشگر Immersive (بوم بلوک‌ها + Inspector + نسخه‌ها + سئو) — الگوی Canvas+Inspector.

API: pages CRUD + publish + restore + revisions + GET /api/v1/site/pages/{path} + blocks/schema.

Frontend: ویرایشگر بلوکی (DragDropList + SchemaForm + Jodit + MediaPicker) + پیش‌نمایش /preview + revalidate + cacheHandler Redis.

تسک ۱.۲ — صفحه ۱.۱۵: اشتراک من

UIUX: وضعیت پلن + فاکتورها + تاریخچه + حالت تعلیق + جریان پرداخت Stepper.

API: subscription + invoices + pay + GET /api/subscription-status?site_id=.

Frontend: بخش اشتراک + پرداخت → درگاه مرکزی + suspension_mode.

تسک ۱.۳ — صفحه ۲.۴: صورتحساب/Billing مرکزی

UIUX: Tab پنج‌گانه (پلن/فاکتور/پرداخت/کنترل تعلیق/درگاه).

API: plans/invoices/payments/suspended + suspend|resume|delete + gateway + webhook + Cron (D-7..D+7).

Frontend: ۵ تب + کنترل تعلیق (مهم‌ترین) + فاکتور قابل چاپ.

تسک ۱.۴ — صفحه ۲.۲: مدیریت مشتریان مرکزی

UIUX: Master-Detail با Drawer عریض + تب‌ها + ارتقا تیر + توکن پشتیبانی.

API: clients CRUD + upgrade-tier + support-token + suspend/resume/delete + backups/restore.

Frontend: لیست + Drawer + ارتقا (ConfirmDialog دو مرحله‌ای) + توکن (کپی + TTL).

🟦 مرحله ۲ — چهارچوب UI

تسک ۲.۱ — ورود + 2FA

UIUX: کارت دو گام. API: login + 2fa/verify + logout/refresh + forgot/reset. Frontend: فرم + سشن httpOnly + rate limit.

تسک ۲.۲ — داشبورد

UIUX: خوش‌آمد + ۴ کارت + هشدار + ویجت پلاگین. API: dashboard/stats + alerts + widgets. Frontend: اسلات ویجت داینامیک.

تسک ۲.۳ — تنظیمات سایت + شبکه‌ها

UIUX: فرم کارتی + لیست شبکه‌ها. API: settings/site + settings/socials. Frontend: فرم + SaveBar + MediaPicker.

تسک ۲.۴ — صفحه ۱.۱۴: قالب پنل مدیریت ⭐

UIUX: گرید ۵ کارت (مینیاتور Token-Driven) + پیش‌نمایش زنده + SaveBar + تنظیمات پیشرفته.

API: GET/PUT /api/v1/ui-settings + GET /api/v1/themes/panel.

Frontend: ThemeCard + AppearancePanel + State Machine + ۱۱ حالت مرزی.

🟩 مرحله ۳ — وابستگی‌های فنی

تسک ۳.۱ — مدیریت فایل (Media Library)

UIUX: گرید/لیست + DropZone + Drawer + سطل زباله + MediaPicker. API: media CRUD + presign + restore + permanent. Frontend: گالری + MediaPicker + نشانگر مصرف.

تسک ۳.۲ — داشبورد مرکزی

UIUX: ۴ کارت + هشدار اکشن‌دار + نمودار. API: dashboard/stats + charts. Frontend: داشبورد + Chart.js.

تسک ۳.۳ — مدیریت چابکان (اسکلت)

UIUX: Ops Console. API: wallet + services + start/stop/restart/resize + deployments + reconciliation. Frontend: StatusBadge + ActionMatrix.

🟦 مرحله ۴ — تکمیل محصول

تسک ۴.۱ — هدر/فوتر + بلوک‌های سایت

UIUX: Widget Area + Tab نوع صفحه. API: layouts/header + footer + page-types + blocks. Frontend: DragDropList + SchemaForm.

تسک ۴.۲ — قالب‌های سایت

UIUX: Theme Gallery. API: themes CRUD + upload + activate + preview. Frontend: گالری + revalidate + purge CDN.

تسک ۴.۳ — تعلیق عمومی (سمت سایت)

UIUX: تمام‌صفحه با برند. API: GET /api/v1/site/status + polling. Frontend: صفحه تعلیق + suspension_mode.
