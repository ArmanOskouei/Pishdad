بخش ۱ — پنل مشتری (۱۴ صفحه + ۱ عمومی)

۱.۱ — ورود + 2FA کم

مشخصات: ایمیل/نام کاربری + رمز + گام دوم کد 2FA + فراموشی رمز. اگر معلق → مستقیم به اشتراک. پیام خطای یکسان.

وایرفریم: کارت وسط (~۴۰۰px) + لوگو. دو گام در یک کارت (انیمیشن). ⭐ حالت معلق → بعد از گام ۱ به «اشتراک من» + بنر زرد.

۱.۲ — داشبورد متوسط

مشخصات: کارت آمار + ویجت پلاگین (با حالت خالی) + هشدارها + میانبرها.

وایرفریم: ردیف ۱ خوش‌آمد+۳ میانبر | ردیف ۲ چهار کارت (اشتراک معلق → قرمز) | ردیف ۳ بنر هشدار | ردیف ۴ گرید ویجت ۲×۲ با حالت خالی.

۱.۳ — مدیران + نقش‌ها متوسط

مشخصات: لیست مدیران + نقش/دسترسی. ⚠️ سوپرادمین در هیچ‌جا لیست نمی‌شود.

وایرفریم: Tab دوگانه (مدیران/نقش‌ها). جدول + مودال + پنل چک‌باکس گروه‌بندی.

۱.۴ — پروفایل متوسط ⭐ «Section Slot»

مشخصات: اطلاعات پایه + رمز + بخش‌های 2FA داینامیک (پلاگینی).

وایرفریم: دو ستونه. چپ = Container با اسلات رندر داینامیک پلاگینی. ⚠️ این الگو کلید سیستم است — در داشبورد/تنظیمات/سایدبار هم لازم.

۱.۵ — مدیریت صفحات زیاد ⭐⭐ (مهم‌ترین)

مشخصات: لیست + ویرایشگر بلوکی (Jodit + درگ‌اندروپ) + تاریخچه نسخه + سئو + پیش‌نمایش + انتشار.

وایرفریم — دو حالت:

  • لیست: نوار ابزار + جدول (عنوان/اسلاگ/وضعیت Badge/اکشن)
  • ویرایشگر (Immersive بدون سایدبار): تاپ‌بار (ذخیره پیش‌نویس/پیش‌نمایش/انتشار) + بوم بلوک‌ها (درگ + drop zone + Drawer کتابخانه بلوک + Jodit داخل بلوک) + سایدبار Inspector (عمومی/سئو/نسخه‌ها)

⭐ الگو: «Canvas + Inspector» (مثل Webflow). «انتخاب تصویر» → MediaPicker. بنر «ادمین دیگری در حال ویرایش».

۱.۶ — مدیریت فایل متوسط

مشخصات: گالری/لیست + آپلود + سطل زباله + alt/URL.

وایرفریم: گرید/لیست + آپلود DropZone + Drawer جزئیات. ⚠️ MediaPicker = اولین کامپوننت (۵ صفحه وابسته). نشانگر مصرف تیر.

۱.۷ — تیکت‌ها متوسط

مشخصات: لیست + گفتگو + پاسخ + وضعیت + اعلان.

وایرفریم: Master-Detail اسپلیت (RTL: لیست راست/گفتگو چپ). حباب چت + نوار پاسخ + چک‌باکس اطلاع‌رسانی.

۱.۸ — تنظیمات سایت کم

مشخصات: عنوان/لوگو/فاوآیکون/تلفن/ایمیل. وایرفریم: فرم کارتی + Sticky SaveBar.

۱.۹ — شبکه‌های اجتماعی کم

مشخصات: لینک + آیکون. وایرفریم: لیست ردیفی + آیکون پیش‌فرض + سوییچ + Empty state.

۱.۱۰ — پلاگین‌ها متوسط

مشخصات: لیست + آپلود + فعال/غیرفعال + هشدار آپدیت. ⚠️ نصب/حذف فقط سوپرادمین.

وایرفریم: جدول/کارت + سوییچ + Badge آپدیت. ⚠️ رندر شرطی نقش (can(action)).

۱.۱۱ — هدر/فوتر زیاد ⭐ — «Widget Area»

مشخصات: درگ‌اندروپ ویجت‌ها (لینک/لاگین/منو/لوگو) در هدر/فوتر.

وایرفریم: پالت ویجت (راست) + بوم دو ناحیه (چپ) + Drawer تنظیمات (SchemaForm) + پیش‌نمایش زنده. ⚠️ با ۱.۱۲ یک طراحی مشترک.

۱.۱۲ — بلوک‌های سایت زیاد ⭐

مشخصات: درگ‌اندروپ بلوک‌های هر نوع صفحه. وایرفریم: Tab به‌ازای نوع صفحه + درگ + سوییچ + Drawer تنظیمات. ⚠️ فهرست انواع صفحه تعریف نشده.

۱.۱۳ — قالب‌ها متوسط

مشخصات: گالری + فعال‌سازی + پیش‌نمایش + آپلود. وایرفریم: Theme Gallery (وردپرس). ⚠️ پیش‌نمایش iframe یا تصویر؟ (MVP: تصویر).

۱.۱۴ — قالب پنل مدیریت زیاد ⭐ (ظاهر پنل ادمین)

مشخصات: این صفحه برای شخصی‌سازی ظاهر خود پنل است (جدا از ۱.۱۳ که قالب سایت را مدیریت می‌کند). قالب پنل با CSS Variables (تغییر پویا بدون رندر مجدد) و ذخیره per-user.

  • گرید ۵ کارت قالب (سپیده/عملیات/آریا/نرم/دیوان) با پیش‌نمایش مینیاتوری
  • ⭐ پیش‌نمایش زنده: کلیک روی کارت = اعمال فوری روی همان پنل (بدون ذخیره)
  • نشان «✔ فعال» برای قالب فعلی + نشان «پیش‌نمایش» هنگام انتخاب
  • نوار ذخیره چسبان: «انصراف از پیش‌نمایش» + «تأیید و ذخیره قالب»
  • سوییچ لایت/دارک + ۲-۳ رنگ‌بندی پیشنهادی (Preset) هر قالب (۱۵ ترکیب)
  • تنظیمات پیشرفته (اختیاری): شعاع/تراکم/فونت

وایرفریم: هدر (عنوان + نشان «قالب فعال») + گرید کارت‌های قالب (پیش‌نمایش مینیاتوری) + نوار ذخیره چسبان پایین.

طراحی نهایی UIUX (قابل اجرا):

  • State Machine: یک شیء AppearanceState = {dir, preset, mode, radius, density, fontSize}. فازها: saved → previewing(dirty) → confirmed|canceled. هر ورودی → mutate() (پیش‌نمایش)، confirm فقط با isDirty، cancel کل draft را دور می‌ریزد، reset از مسیر mutate.
  • کامپوننت ThemeCard: کارت role="radio" + کیبورد. وضعیت‌ها: is-active (سبز ✔) / is-previewing (کهربایی ◉ — غلبه بر سبز) / is-default (چیپ پیش‌فرض) / is-disabled.
  • مینیاتور Token-Driven: روی .tc-preview شش اتریبیوت (direction/mode/preset/radius/density/font) — بدون رنگ هاردکد، همه از var(--bg), var(--sidebar-bg), var(--primary), var(--grad). ساختار: مینی-سایدبار (راست RTL) + مینی-تاپ‌بار + مینی-بادی. هاور scale(1.04). امضای بصری از توکن‌ها (دیوان = سایدبار سرمه‌ای، آریا = گرادیان لوگو).
  • پریست‌ها داخل کارت (radiogroup + swatch با --swatch + تیک). لایت/دارک در SaveBar (قطاعی).
  • کامپوننت AppearancePanel (مشترک با پروفایل ۱.۴): mode/radius/density/font با SegmentedControl. در ۱.۱۴ آکاردئونی بسته.
  • ۱۱ حالت مرزی: ترک صفحه → مودال + beforeunload | لایت/دارک و پریست جزو draft | کلیک روی قالب فعال → پیش‌نمایش مجدد | تأیید بدون تغییر → disabled | شکست شبکه → خطا + تلاش مجدد | اولین ورود → پیش‌فرض نقش (سپیده مشتری/عملیات مرکزی) | ریلود → برگشت به saved + توست | قالب دارک در لایت → hint.
  • ۱۵ ترکیب پریست: سپیده (فیروزه‌ای/نیلی/یاقوتی) • عملیات (ایندیگو/ماتریس/امنیت) • آریا (بنفش-صورتی/اقیانوس/غروب گرادیانی) • نرم (سفالی/آسمانی/لیمویی) • دیوان (آبی/سبز دولتی/سرمه‌ای). --primary-soft با color-mix مشتق شود.
  • DoD: ماشین حالت کامل | مینیاتور بدون هاردکد | پریست در کارت + مود در SaveBar | آکاردئون | ۱۱ حالت مرزی | بازنشانی + تمایز کهربایی/سبز | ThemeCard/AppearancePanel مستقل | RTL logical + اسکلتون | ضد FOUC.

۱.۱۵ — اشتراک من زیاد ⭐ (قلب حلقه پول)

مشخصات: وضعیت پلن + دوره (۲۰٪ تخفیف سالانه) + فاکتور + پرداخت (درگاه در مرکزی) + تاریخچه + حالت تعلیق.

وایرفریم: کارت وضعیت + فاکتورها (دکمه پرداخت سبز) + ⭐ جریان پرداخت = Stepper جدا.

۱.۱۶ — تعلیق عمومی کم (سمت سایت)

مشخصات: پیام «اشتراک تمام شده» بدون لینک پنل. وایرفریم: تمام‌صفحه با برند سایت + دکمه تماس پشتیبانی.

بخش ۲ — پنل مرکزی (۷ صفحه — فقط کارفرما)

۲.۱ — داشبورد مرکزی متوسط

۴ کارت + هشدارهای اکشن‌دار (کیف پول قرمز/استخر زرد/تعلیق زرد/دیپلوی قرمز) + نمودارها. «نگاه اول صبح» کارفرما.

۲.۲ — مدیریت مشتریان زیاد ⭐ — Master-Detail با Drawer

جدول غنی (نام/دامنه/تیر Tag/اشتراک Badge/سلامت دایره‌ای) + Drawer عریض (~۶۴۰px) با تب‌ها (اطلاعات/سرویس‌ها/بکاپ‌ها/فاکتورها) + «ارتقا تیر» (ConfirmDialog دومرحله‌ای) + «دسترسی پشتیبانی» (توکن یکبارمصرف + TTL).

۲.۳ — مدیریت چابکان زیاد ⭐ — Ops Console

ردیف‌ها: کیف پول + استخر سرویس / سرویس مشتریان (start/stop/restart با ConfirmDialog) / دیپلوی‌ها / Reconciliation. ⭐ StatusBadge + ActionMatrix.

۲.۴ — صورتحساب/Billing زیاد ⭐ — Tab پنج‌گانه

۱) پلن‌ها ۲) فاکتورها (قابل چاپ/PDF) ۳) پرداخت‌ها ۴) ⭐ کنترل تعلیق (مشتریان معلق + روز باقی‌مانده از ۷ روز) ۵) تنظیمات درگاه (ماسک + تست).

۲.۵ — مانیتورینگ متوسط

تب‌ها: گرید سلامت / لاگ متمرکز / آپتایم ۳۰ روز. ⚠️ منبع داده heartbeat تعریف نشده.

۲.۶ — آپدیت‌ها متوسط

جدول نصب‌ها + Badge آپدیت + رول‌اوت پلکانی (پایلوت→بچّه→همه) + Rollback برجسته. ⚠️ بدون مفهوم canary.

۲.۷ — پروفایل اپراتور کم

2FA سخت‌افزاری + مدیریت توکن (بازتولید → step-up auth) + Kill-Switch (قرمز + تأیید دومرحله‌ای) + لاگ فعالیت.
